# CS^3 Lab Website

This repository hosts the official website of the **Cloud and Smart System Services Lab (CS^3 Lab)** at [cs3-lab.github.io](https://cs3-lab.github.io).

## 🔍 About CS^3 Lab

The **Cloud and Smart System Services Lab (CS^3 Lab)** is dedicated to cutting-edge research at the intersection of cloud computing, smart systems, and secure, intelligent architectures.

> **Our mission** is to advance the state-of-the-art in cloud and smart system services while fostering innovation that impacts both academia and industry. With a commitment to excellence, we aim to position NITK Surathkal as a global leader in cloud and smart systems research. Whether you're curious about distributed systems, AI-driven optimizations, or secure architectures, CS^3 Lab is where ideas become reality.

## 🌐 Website Structure

The website includes the following sections:
- **[Home](https://cs3-lab.github.io/index.html)** – Introduction to the lab, highlights, and quick navigation.
- **[Domain](https://cs3-lab.github.io/domain.html)** – Overview of research domains and key areas of focus.
- **[Projects](https://cs3-lab.github.io/project.html)** – Highlights of active and completed research initiatives.
- **[Publications](https://cs3-lab.github.io/publication.html)** – Peer-reviewed articles, conference papers, and books authored by lab members.
- **[Members](https://cs3-lab.github.io/team.html)** – Profiles of current lab members, alumni, and collaborators.
- **[Gallery](https://cs3-lab.github.io/gallery.html)** – Timeline of events, lab milestones, and achievements.

## 🚀 Deployment

The website is built using HTML, CSS, and JavaScript, and is deployed via **GitHub Pages**. All updates to the `main` branch are automatically reflected on the live site.

For any inquiries or updates, reach out to the lab coordinators via the details provided on the [Team Page](https://cs3-lab.github.io/team.html).
